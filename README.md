# Bùi Đặng Quế Trân · Gia sư IELTS

Trang profile tĩnh (HTML/CSS thuần), host bằng GitHub Pages.

## Cấu trúc

- `index.html` — toàn bộ trang
- `anh-web.jpg` — ảnh chân dung đã nén dùng trên trang (`anh.jpg` là ảnh gốc)

## Đăng lên GitHub Pages

1. Tạo repository mới trên GitHub (ví dụ `quetran-ielts`), để **Public**.
2. Tải các file trong thư mục này lên repository (kéo thả trên web, hoặc dùng git).
3. Vào **Settings → Pages**, mục *Source* chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)`, bấm **Save**.
4. Sau 1–2 phút trang sẽ có ở `https://<username>.github.io/<tên-repo>/`.

Mẹo: đặt tên repository là `<username>.github.io` thì địa chỉ sẽ gọn là `https://<username>.github.io/`.
